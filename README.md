# My-Power-BI-Projects
Power BI Retail & Sales Data Analysis
📊 Data Technician Bootcamp Project

This project was completed as part of my Data Technician Bootcamp, where I developed practical skills in Power BI, data transformation, data modelling, DAX, report design and data visualisation.

The project focused on taking raw retail and sales data, preparing it for analysis, and turning it into interactive reports that make trends and key insights easier to understand. The bootcamp work included dedicated Power BI labs covering data cleaning and transformation, semantic models, DAX calculations and report design.

🛠️ Skills Demonstrated
Data Cleaning & Transformation
Used Power Query to clean and transform raw data
Prepared datasets for analysis and reporting
Changed and managed data types
Structured data so it could be used effectively within Power BI
Applied data transformation techniques to improve data quality
Data Analysis & DAX
Created DAX calculated columns
Created DAX measures for analysing sales data
Used DAX calculations to create additional insights from the dataset
Developed an understanding of filter context and time intelligence
Worked with semantic models to support analysis and reporting
Interactive Reports
Built interactive Power BI reports
Used slicers and filters to allow users to explore specific parts of the data
Added interactive controls to make reports easier to navigate
Designed reports to present important information clearly and logically
📈 Data Visualisation

The project included a range of visualisations to communicate retail and sales performance, including:

📊 Bar charts – comparing sales across products and categories
📈 Line charts – showing sales and performance trends over time
🥧 Pie charts – displaying category and sales proportions
🗺️ Maps – visualising geographical sales information
📌 Interactive report elements – allowing users to filter and explore the data
📖 Data Storytelling

A key part of the project was learning how to use data storytelling to turn analysis into information that is easy to understand.

Rather than simply displaying large amounts of data, I focused on using appropriate visualisations, filters and calculated measures to highlight:

Sales trends
Product performance
Category differences
Geographical patterns
Changes in performance over time
Key insights that could support business decisions
🎯 Project Outcome

This project strengthened my ability to take data through the full analysis process:

Raw Data → Power Query → Data Model → DAX → Visualisations → Interactive Report → Business Insights

It demonstrates my developing ability to use Power BI to clean, analyse and visualise retail and sales data, while presenting findings through clear and interactive dashboards.
